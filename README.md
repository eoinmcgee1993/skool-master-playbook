# Skool Master Playbook

Autonomous, authorised course-material ingestion and publication pipeline.

## Boundary
This repository owns source intake, course structure, raw artefacts, provenance and publication outputs.

It does not bypass authentication, defeat access controls, or scrape protected Skool content without an authorised export/API/input.

## Pipeline
authorised source -> ingest -> normalise -> provenance -> handoff -> playbook engine -> publish
